# No Silent Data Upgrade Audit v1

Soul Codex must never promote unverified, approximate, fallback, or AI-inferred data into fact status without explicit provenance and verification state.

Pass criteria:

- zero fabricated astrology fallbacks
- zero unverified placements rendered as fact
- zero confidence values without source
- zero UI-originated verification promotion
- zero AI synthesis of unresolved placements

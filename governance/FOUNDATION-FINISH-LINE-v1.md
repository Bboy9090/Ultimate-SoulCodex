# Soul Codex Foundation Finish Line v1

## Mission

Ship a trustworthy, clarity-first Soul Codex Foundation release that lets a user create one profile, receive a deep but readable explanation, inspect why the app believes each claim, view Timeline, and use Compatibility without rebuilding their own profile.

## Product Standard

Maximum clarity through meaningful depth.

Every user-facing insight must answer:

1. What is the pattern?
2. Why may it happen?
3. What need or protection may sit beneath it?
4. What is the gift?
5. What is the cost when overused?
6. What can the user do next?
7. What evidence supports the conclusion?

Depth must create clarity, not volume.

## Release Scope

### Included

- One persistent Soul Profile reused across modules
- Clarity-first Home and navigation
- Evidence-traceable reading experience
- Essential / Complete / Technical reading depth
- Timeline with deterministic numerology cycles
- Compatibility Hub that reuses the saved profile
- Universal sign/type compatibility explorer
- Romantic, sexual, intellectual, friendship, growth, friction, and repair dimensions
- Explicit unresolved states for unverified astrology
- Offline/PWA behavior
- Mobile web readiness
- Foundation governance and release receipts

### Explicitly Deferred

- Behavioral prediction engine
- Companion memory
- Soul Replay
- Enterprise HIOS modules
- Full relationship graph
- Journal intelligence
- Unverified Moon, Ascendant, houses, Human Design, or planetary interpretations

## Non-Negotiable Rules

1. Calculated facts are never invented or altered by AI.
2. Interpretation cannot create verification state.
3. Unknown data is labeled, never silently guessed.
4. The user creates their own profile once.
5. Compatibility reuses that profile.
6. No hardcoded astrology fallbacks.
7. No unsupported confidence percentages.
8. Every major conclusion is inspectable.
9. No new feature modules until the Foundation gates pass.
10. The user should leave with clarity about who they are, why a pattern appears, and what to do next.

## Acceptance Gates

### Gate A — Trust

- No silent astrology upgrades
- No unverified placement interpretation
- No UI-created verification
- No invented confidence values
- AI receives verified facts and explicit unresolved states only

### Gate B — Clarity

- Essential mode answers the core pattern, why, gift, and next move
- Complete mode adds hidden experience, cost, relationships, and repair
- Technical mode exposes evidence and limitations
- No repeated filler paragraphs
- No wall of system labels without synthesis

### Gate C — One Profile

- Create profile once
- Home recognizes the active profile
- Identity opens the same profile
- Timeline loads the same profile
- Compatibility uses the same profile
- Refresh and restart preserve the profile

### Gate D — Compatibility

- Universal match explorer remains available
- Strongest natural matches shown by dimension
- Highest-friction matches explained without declaring people inherently bad
- Growth-potential matches included
- Specific-person comparison asks only for the other person's data
- Missing birth time produces partial analysis, not fabricated precision

### Gate E — Runtime

- TypeScript and build pass
- Core tests pass
- Browser lifecycle passes
- PWA offline restart passes
- Container smoke passes
- No critical console errors

### Gate F — Mobile

- iOS package resolution validated
- Archive and export validated
- Android build validated
- Mobile layouts manually checked

## Definition of Done

Foundation is complete when a real user can:

1. Create one profile.
2. Receive a deep, understandable reading.
3. See what is known, unknown, and why.
4. Open Timeline without re-entering data.
5. Open Compatibility without re-entering their own data.
6. Explore strongest, weakest, sexual, intellectual, emotional, friendship, and growth matches.
7. Add another person once for a specific comparison.
8. Refresh, restart, and use the core app offline.
9. Use the mobile app without release-blocking build failures.

No claim of completion is valid without the evidence receipts for these steps.

# Soul Codex: Canonical Roadmap & Architecture

## Canonical Architecture

### FOUNDATION: The Ground Truth
Verified calculations, profile creation and storage, offline operation, confidence states, deterministic facts, stable APIs, testable outputs.

**What this layer answers**: Can we calculate accurately? Can we store reliably? Can we prove it?

### INTELLIGENCE: The Understanding
Synthesis engine, evidence tracing, context engine, contradiction detection, dominance ranking, versioning, transparent interpretation.

**What this layer answers**: Why are we saying this? Where does this come from? How confident are we?

### PREDICTION: The Foresight
Situational behavior modeling, likely response patterns, decision-path comparison, risk and friction prediction, timing guidance, recommendation confidence.

**What this layer answers**: When X happens, what will I probably do? Which choice fits my nature? When is the right timing?

### COMPANION: The Coaching
Memory engine, mirror engine, Soul Replay, journaling, pattern callbacks, progress tracking, adaptive AI guidance.

**What this layer answers**: Have I grown? What patterns keep showing up? What should I work on next?

### ENTERPRISE: The Scale
Team intelligence, leadership profiles, communication mapping, organizational friction analysis, role alignment, group decision support, enterprise controls and reporting.

**What this layer answers**: How do we work together? Who should lead this? Where will we clash?

---

## Dependency Chain

```
FOUNDATION
    ↓
INTELLIGENCE
    ↓
PREDICTION
    ↓
COMPANION
    ↓
ENTERPRISE
```

**Critical rule**: No layer should leapfrog the one beneath it.

- Prediction without trustworthy intelligence = confident nonsense
- Companion without memory = repetitive chat
- Enterprise without validated foundations = expensive theater in a blazer

Each layer is built on the stability of all layers below it.

---

## Critical Caveat: Timelines Are Capacity Estimates, Not Promises

One year is plausible **only if**:

✓ Scope remains controlled within each phase  
✓ Each layer foundation is genuinely stable before moving up  
✓ Each phase has strict exit criteria before the next begins  
✓ Technical debt is paid as you go, not deferred  

**If these conditions fail**, timeline extends proportionally. That's acceptable.

**What is not acceptable**: Shipping a phase before it's ready to support the next layer. A shaky FOUNDATION makes INTELLIGENCE impossible. A weak INTELLIGENCE makes PREDICTION dangerous.

## Exit Criteria (What "Done" Means)

### FOUNDATION is done when:
- ✅ All calculations match manual verification
- ✅ Offline mode works without network
- ✅ Data persists across sessions
- ✅ 4/4 regression gates pass
- ✅ No critical bugs in 2-week stability window

### INTELLIGENCE is done when:
- ✅ Gold Standard Dataset complete (100 charts)
- ✅ Evidence traces 100% of claims
- ✅ Confidence levels are accurate (calibrated)
- ✅ Users report "I understand why"
- ✅ No contradictions between systems

### PREDICTION is done when:
- ✅ Behavioral predictions validated 80%+ vs. journals
- ✅ Decision recommendations measurably improve outcomes
- ✅ Timing guidance aligns with user experience
- ✅ Risk predictions are not over-confident
- ✅ No cases of "prediction was wildly wrong"

### COMPANION is done when:
- ✅ Memory engine tracks 12+ months of patterns
- ✅ Soul Replay shows measurable growth
- ✅ Users return weekly for coaching
- ✅ Mirror engine shows meaningful self-insight
- ✅ Journaling integration is seamless

### ENTERPRISE is done when:
- ✅ Team intelligence produces actionable org insights
- ✅ Leadership profiles improve hiring decisions
- ✅ Communication mapping reduces conflict
- ✅ Customers report ROI
- ✅ Enterprise controls and audit trails work
